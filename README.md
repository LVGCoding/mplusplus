# mplusplus
M++ (bundled with the M++ Editor) is a work-in-progress programming language written in Odin that combines the visibility of LaTeX with the functionality of raw code.

Dependencies:
[Orui](https://github.com/andzdroid/orui/tree/bf7a2cbcdfe9139a5f1bf6560570fa392e46bd73)

Building:
Ensure you have a [valid Odin installation](https://github.com/odin-lang/Odin/releases) for your hardware, and run "odin build /src" from the root directory.
